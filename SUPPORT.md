# OpenUPI support

OpenUPI currently publishes documentation and proposed product contracts. There is no live payment service, customer account, installable package or transaction-support desk.

| Need | Where to go |
| --- | --- |
| Unclear or incorrect documentation | Documentation issue template |
| Proposed feature or scope improvement | Feature request template |
| Reuse or commercial permission | Permission request template and [PERMISSIONS.md](PERMISSIONS.md) |
| Vulnerability or leaked secret | [SECURITY.md](SECURITY.md); do not post details publicly |
| Conduct concern | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Existing real-world payment problem | The actual merchant, bank or payment provider involved |

Include a document path, relevant section and synthetic example. Search existing issues first. Keep bank statements, personal contact information, UTRs, OTPs, credentials and customer data out of public reports.

Maintainers respond as available. No response-time commitment, paid support, recovery service or refund execution is offered.
